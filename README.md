# Cyber WhatsApp Pro Web

A modern, premium landing page for distributing the **Cyber WhatsApp Pro** Chrome extension - a bulk WhatsApp automation tool.

![Cyber WhatsApp Pro](https://res.cloudinary.com/dwsl2ktt2/image/upload/v1778439347/cybbber_xhblm2.png)

## 🚀 Features

- **Modern UI/UX** - Clean, premium SaaS-style design
- **Responsive Design** - Mobile-first approach
- **Chrome Detection** - Warns non-Chrome users
- **Step-by-Step Installation Guide** - Visual cards with instructions
- **Copy Instructions** - One-click copy functionality
- **Video Guide Section** - YouTube embed placeholder
- **Pricing Plans** - Monthly and yearly options
- **Floating WhatsApp Support** - Quick contact button
- **Smooth Animations** - Hover effects and transitions

## 🛠️ Tech Stack

- **React 18** - UI Framework
- **TypeScript** - Type Safety
- **Tailwind CSS v4** - Styling
- **Shadcn UI** - Component Library
- **Lucide React** - Icons
- **Framer Motion** - Animations
